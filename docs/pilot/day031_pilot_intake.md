# Day 031 Pilot Intake

## 目标

把本地 MVP 转成真实试点前的资料收集流程。当前动作不是继续加功能，也不是马上接数据库，而是收集第一家真实涂料门店的最小交付资料。

## 使用边界

- 可以用于真实试点访谈和资料整理。
- 不要接真实生产数据。
- 不要在认证、RLS、备份、审计日志完成前让多人使用。
- 不要在字段确认前把本地样例直接替换成数据库写入。

## 访谈清单

### 门店基本信息

- 门店名称和所在城市是什么？
- 店主、店员、记账人员分别是谁？
- 每天大概几点开门、几点关门、几点做日结？
- 第一周只允许谁录入真实数据？

### 商品和库存起点

- 商品清单来自哪里：表格、纸本、收银系统，还是货架盘点？
- 每个商品是否至少有名称、规格、单位、进价、售价、库存、低库存线？
- 是否存在同名不同规格、同规格不同品牌、散装或按公斤销售？
- 第一周先导入全部商品，还是只导入高频商品？

### 客户和期初应收

- 需要先导入哪些客户？
- 没有手机号的客户用什么识别？
- 期初应收能否按客户给出金额和备注？
- 第一周是否允许新增客户？

### 供应商和期初应付

- 常用供应商有几家？
- 是否需要手机号、联系人、账期或备注？
- 是否有期初应付？
- 第一周采购入库是否只记录数量和金额？

### 销售单格式

- 销售单必须打印哪些字段？
- 常用付款方式有哪些？
- 折扣是整单折扣、单行折扣，还是两者都要？
- 客户单据是否需要门店电话、地址或备注？

已确认约束：

- 门店已有预印销售单据。
- 纸张大小是 32 开。
- 后续打印模板需要支持预印单据位置适配，并考虑双联单输出。

### 每日结账

- 关门前最先看哪些数字？
- 是否按付款方式拆分收款？
- 是否列出当天未收清订单？
- 日结结果是打印、截图、导出，还是只在页面查看？

### 第一周试点边界

- 每天预计录入多少张销售单？
- 是否允许多人同时操作？
- 谁负责每天核对库存和备份数据？
- 系统不可用时如何回退？

## 交付 Gate

1. 确认真实字段后，再调整数据库 schema。
2. 决定首店数据是手工录入还是 CSV 导入。
3. 字段未确认前，不接生产 Supabase 写入。
4. 真实多人使用前，必须完成认证、RLS、备份和审计日志。

## 完成标准

拿到一位真实店主足够配置首个试点的数据，不被 ERP 级需求拖偏。
