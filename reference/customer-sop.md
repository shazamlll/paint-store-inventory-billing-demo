# 客户操作 SOP

本文面向门店老板、店员和实施人员，说明系统在真实门店里的推荐使用顺序。它不是技术接口文档。

## 角色建议

### 老板 / 店主

适合操作：

- 查看经营看板。
- 查看日报。
- 管理商品、客户、供应商。
- 做库存调整。
- 核对应收应付和库存。
- 决定是否执行数据导入、备份和上线。

### 店员

适合操作：

- 开销售单。
- 打印销售单。
- 做采购入库。
- 查看商品和客户。
- 查看库存流水和低库存提醒。

### 财务 / 记账人员

当前系统还没有完整财务后台。可以先查看看板和报表，但独立收款、冲销、退款、正式对账仍是后续工作。

## 每日开店前

1. 登录系统。
2. 确认当前门店名称和角色显示正确。
3. 打开「经营看板」查看昨日或当前库存风险。
4. 打开「低库存提醒」，确认今天需要补货的商品。
5. 如果有新增商品、客户或供应商，先在对应资料页维护。

## 新增或维护基础资料

### 商品

1. 进入「商品列表」。
2. 如果商品不存在，进入商品编辑页新增。
3. 填写名称、规格、单位、成本价、销售价、当前库存和低库存阈值。
4. 保存后回到商品列表确认可见。

建议：

- 同品牌不同规格应拆成不同商品。
- 散装、按公斤、按桶销售的商品应明确单位。
- 低库存阈值先用保守值，实际运行一周后再调整。

### 客户

1. 进入「客户列表」。
2. 新增客户姓名、电话、备注和期初应收。
3. 保存后开销售单时选择该客户。

建议：

- 散客可以保留一个默认客户。
- 常赊账客户必须单独建档，方便后续应收扫描。

### 供应商

供应商当前通过后端接口支持写入，前端完整维护体验仍可继续增强。实施时应至少准备供应商名称、电话、备注和期初应付。

## 销售开单 SOP

1. 进入「开销售单」。
2. 选择客户。
3. 添加商品行。
4. 填写数量、单价、优惠。
5. 填写本次已收金额。
6. 检查应付合计、已收款和待收款。
7. 点击保存销售单。
8. 保存成功后，确认「已保存销售单」出现该单据。
9. 打开销售单明细或「打印销售单」进行打印。

注意事项：

- 库存不足时，系统会阻止写入。
- 已收金额不能大于订单金额。
- 销售单保存后会影响库存、库存流水、应收和报表。
- 当前打印页只支持基础浏览器打印，32 开预印双联套打模板还未完成。

## 采购入库 SOP

1. 进入「采购入库」。
2. 选择供应商。
3. 添加商品行。
4. 填写数量和进货单价。
5. 填写本次已付款金额。
6. 保存采购单。
7. 保存成功后，确认商品库存增加。
8. 在库存流水中确认对应采购入库记录。

注意事项：

- 采购单保存后会影响库存、库存流水和供应商应付。
- 付款金额不能超过采购单金额。
- 如果供应商或商品不是数据库来源，保存可能不会走正式服务端事务。

## 库存调整 SOP

适用场景：

- 盘点发现账实不符。
- 商品破损、报损。
- 录入期初时需要修正库存。

操作：

1. 进入「库存调整」。
2. 选择商品。
3. 输入调整数量，增加为正数，减少为负数。
4. 填写原因。
5. 保存。
6. 在「库存流水」确认生成 adjustment 记录。

注意：

- 调整后库存不能小于 0。
- 必须填写原因。
- 调整是追加流水，不应直接删除历史记录。

## 每日结账 SOP

1. 进入「每日结账」。
2. 查看今日销售额、收款、应收新增和低库存。
3. 查看今日销售单列表。
4. 打印报表或保存截图。
5. 对照现金、微信、支付宝、银行卡实际收款做人工核对。

当前限制：

- 系统还没有按付款方式拆分的完整收款对账。
- 独立客户还款不在当前 workflow 内。
- 日报可打印，但还不是正式财务结账系统。

## 客户还款 SOP

当前不建议在系统里独立登记客户还款，因为该功能尚未实现。临时建议：

1. 如果客户是在开销售单时付款，直接在销售单里填写已收金额。
2. 如果客户后续还旧账，先在线下记录。
3. 等独立收款 workflow 完成后，再录入或迁移这些还款记录。

后续系统应支持：

- 按客户录入收款。
- 分配到一张或多张销售单。
- 自动减少客户应收。
- 支持冲销、退款和审计记录。

## 打印 SOP

当前：

- 可以通过「打印销售单」打印数据库中最新销售单。
- 可以通过浏览器打印对话框输出。
- 可以打印每日报表。

未完成：

- 32 开纸张尺寸。
- 预印单据套打定位。
- 客户联/存根联双联输出。
- OKI MICROLINE 5200F 真实设备校准。

建议实施顺序：

1. 收集真实预印单纸样。
2. 确认纸张实际宽高。
3. 确认两联方式：同页两份，还是无碳纸复写。
4. 在真实打印机上测试偏移。
5. 将偏移量固化为模板配置。

## 异常处理

### 登录失败

- 检查 Supabase Auth 账号是否存在。
- 检查密码是否正确。
- 检查浏览器是否能访问 Supabase 项目。

### 登录后没有门店

- 检查 `store_members` 是否有该用户记录。
- 检查门店是否 active。
- 检查 membership 是否 active。

### 保存失败

- 查看页面错误提示。
- 常见原因：未登录、没有门店、角色不允许、库存不足、付款金额超过订单金额、Supabase 配置缺失。

### 打印偏位

- 先确认浏览器缩放是 100%。
- 关闭浏览器默认页眉页脚。
- 确认打印机纸张尺寸与系统模板一致。
- 记录水平和垂直偏移量，作为后续模板参数。

## 上线前建议

真实门店使用前至少完成：

- 门店账号和角色核对。
- 商品、客户、供应商导入核对。
- 期初库存和应收应付核对。
- 销售开单、采购入库、库存调整端到端测试。
- 打印模板实机测试。
- 每日备份和恢复流程确认。
- 系统不可用时的线下回退方案。
